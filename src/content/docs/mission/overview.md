光学とSARの基礎から、生成AIで正しいコードを書く方法、結果を検証するファクトチェック、社会課題への提案まで。現場さながらのワークフローを体験する。

## 通しの課題

> **福島の農地を衛星で見る：AIが出した結果は本当に正しいか？**

福島県相馬市・南相馬市の農地を対象に、Sentinel-2（光学）と Sentinel-1（SAR）の時系列から**作付／休耕を判別**する。
毎週、違う層で同じ問いを立てる。

| 週 | その週の問い | 正しさを判断する根拠 |
| --- | --- | --- |
| W1 | その緑は本当に植生か | 反射スペクトルの物理 |
| W2 | その明るさは本当に水田か | 散乱機構 |
| W3 | 光学とSARが食い違ったらどちらを信じるか | 観測条件（軌道・入射角・偏波） |
| W4 | 動いたコードは本当に正しいか | エラーの出ない誤りを狩る |
| W5 | その分類は本当に学習できているか | 疑似ラベルの作り方と限界 |
| W6 | その精度は本当に現場で役に立つか | 費用対効果・2軸評価 |
| W7 | その数字は本当に再現できるか | 1筆=1行・再現性ヘッダ |
| W8 | その判別は本当に信頼できるか | ファクトチェック3層・閾値 |

## 到達目標

1. **生成AIを活用して解析を正しく実装できる。** SARも光学も、基礎原理を理解して手法を再現できる。
2. **衛星データ×データサイエンスを検証できる。** AIの出力を鵜呑みにせず、物理法則・センサ特性から解析結果の正しさを見極める。
3. **解析結果を「届ける」ところまで経験する。** 非専門家にも伝わる提案ストーリーを設計する。

## 前提スキル

- Python の基礎的な読み書きができ、自分でコードを書いたことがある
- 物理基礎またはそれに相当する知識（電磁波の基礎を学ぶ意欲があれば可）
